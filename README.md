# Assignment 01: Time Complexity Analysis

## Question

Write a C program to analyze time complexities in constant time, linear time and quadratic time. Increase the size of input to check the time consumed.

## Notes

- The implementation demonstrates operations with constant time, linear time, and quadratic time complexities.
- Different input sizes are used to observe and compare the time consumed by each operation.
- Sample outputs are included for verification and analysis purposes.
