# Advanced Programming (CSBT215) — Architecture Overview

This repository serves as the definitive codebase for the Advanced Programming curriculum. 

## Repository Architecture

To maintain strict version control and environmental isolation, every module is contained within its own dedicated Git branch. The `main` branch functions exclusively as the routing matrix. 

To review the source code, architecture, and localized execution requirements for any specific module, pull the corresponding branch directly:



```bash
git checkout assignment6      # then read its README.md and source
```
