# Assignment 04: Product Inventory Management

## Question

Create a Python program using a list and dictionary to store products with name and stock quantity.

Display all products whose stock is less than 10.

## Notes

- The implementation uses Python lists and dictionaries to store product information.
- Each product contains a name and stock quantity.
- The program identifies and displays products whose stock quantity is less than 10.
